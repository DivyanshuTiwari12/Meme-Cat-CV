# MemeCatCV - Instagram Cat Mediapipe Program 🐱

A fun OpenCV program that detects facial expressions using MediaPipe and overlays hilarious meme cats in real-time!

![Rigby](Images/cat-disgust.jpeg)

## ✨ Features

- **Real-time face detection** using MediaPipe Face Mesh
- **3 expressive cat meme overlays**:
  - 😲 **Shock Cat** - Wide eyes detected
  - 😛 **Tongue Cat** - Mouth wide open
  - 😠 **Glare Cat** - Squinting eyes
  - 🐱 **Default Larry** - Neutral expression
- **Live facial landmark visualization**
- **Smooth 640x480 cat overlay window**
